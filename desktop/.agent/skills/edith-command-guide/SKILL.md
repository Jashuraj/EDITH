# EDITH Command Guide Drawer

## Implementation
- Mobile UI drawer: `edith/ui/public/mobile/index.html` and `app.js`.

## Features
- Searchable quick-tap command chips.
- Categorized by System, Media, Navigation, Gaming, and Security.
- Instant execution over mobile gateway WebSocket channel.
- Real-time command status feedback on mobile screen.
