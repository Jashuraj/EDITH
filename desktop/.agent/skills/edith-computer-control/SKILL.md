# EDITH Computer Control

## Capabilities
- Process management and window manipulation via `edith/tools/windows.py`.
- Fast desktop automation via `edith/tools/reflex.py`.
- Audio volume, media playback, and system settings control.
- Application launching and process termination with verification.
