# EDITH Holographic HUD & Visual Interface

**Port:** 8794  
**Path:** `edith/ui/public/`  

---

## Features

1. **Iron Man / Ultron Particle Orb:**
   - 2,000 particle WebGL sphere rendered with Three.js.
   - Dynamic concentric gyroscope rings.
   - Real-time color response tracking EDITH state.
2. **Glassmorphic HUD Cards:**
   - System Telemetry sidebar (CPU, RAM, storage, battery, model).
   - Mission Control live output feed.
   - Bottom input bar with instant transmission and Emergency Stop.
3. **Webcam Gesture Tracking:**
   - Touchless controls (pinch to rotate, spread to zoom, hold to pause).
