# EDITH GameStream Integration

## Integration Details
- Implementation: `edith/tools/gamestream.py`.
- Supports Sunshine host and Moonlight client.

## Operating Procedures
- Auto-detect local Sunshine server and Moonlight executable.
- Handle pairing PIN validation and authentication.
- Launch low-latency game streaming sessions.
- Monitor active stream status and frame rates.
